# Голос Праматери

Сюда кладутся записанные реплики Праматери. Когда она произносит совет, `MotherSpeaker` (`scripts/game/mother_speaker.gd`) ищет файл с именем ключа этого совета: сначала `.ogg`, потом `.wav`, потом `.mp3`. Если файл есть, он играет, пока текст печатается в облачке. Если файла нет, она «говорит» молча, только текстом.

Ключи советов задаёт сервер (`server/src/sim/advisor.ts`):

| ключ | о чём |
|---|---|
| `mother` | Праматерь погибла / в опасности |
| `enemy`, `monster` | враг у лагеря, чудище у берега |
| `hunger`, `food` | голод, мало еды |
| `fire` | костёр слабеет |
| `huts`, `full`, `house` | не хватает хижин, лагерь полон, пора дом рода |
| `clay` | нет глины |
| `workshop` | нужна мастерская |
| `site-clay`, `site-wood`, `site-stone` | на стройку не хватает глины, дерева, камня |
| `kiln`, `kiln-wood` | печь обжига и дрова для неё |
| `spring`, `spring-enemy` | источник особой глины свободен или занят соседями |
| `siege` | соседи осаждают тотем |
| `dominance` | отсчёт господства |
| `finale` | Великий ливень близко |
| `water-guns` | соседи стреляют водой |
| `warriors` | пора посвятить воина |
| `losses` | племя тает |
| `rain` | дождь, сырые под открытым небом |

Пример: `huts.ogg` — «Хижин мало — жители спят под открытым небом». Длина 2–4 секунды, моно, 44.1 кГц.

Для озвучки жителей при щелчке по ним позже можно сделать такую же папку `audio/residents/`.
