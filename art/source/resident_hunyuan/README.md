# Житель из Hunyuan 3D — исходник

Сделано владельцем и Claude 22.10.2026 на сайте Tencent Hunyuan 3D (3d.hunyuan.tencent.com, 3D Studio) по ТЗ [`docs/godot/TZ_resident_from_2d.md`](../../../docs/godot/TZ_resident_from_2d.md).

## Цепочка на сайте

1. Геометрия по картинке (владелец): 1,5 млн полигонов.
2. Лоу-поли (`低模生成`): плотность «низкая», топология из четырёхугольников, 3860 вершин.
3. UV-развёртка (`UV展开`), автоматическая.
4. Текстура (`纹理绘制`, по картинкам, 4 вида): `reference/front.png`, `left.png` (смотрит влево), `right.png` (смотрит вправо), `back.png`.
5. Экспорт GLB.

## Что в `resident_hunyuan_lowpoly_textured.glb`

- **Меш:** один, `mesh_rep_0_ori_repair_quad`, 4683 вершины, 7744 треугольника; есть NORMAL и TEXCOORD_0.
- **Материал:** `Material.001` (PBR) с тремя PNG ~4K — цвет `texture_pbr_20250901`, карта нормалей `…_normal`, metallic-roughness. Мелкая лепка запечена в нормали, высокополигональная версия не скачивалась.
- **Размер и ориентация:** высота около 1 м (Z −0,50…0,50), у узла поворот 90° по X. Без скелета и анимаций.
- Вес файла 30 МБ, в основном из-за текстур 4K. Для игры их нужно ужать (2K или 1K, сжатие Godot).
