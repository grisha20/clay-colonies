# Житель «лысый, с повязкой» в Т-позе — исходник Hunyuan 3D

Сделано владельцем и Claude 22.10.2026 на сайте Tencent Hunyuan 3D (3d.hunyuan.tencent.com, 3D Studio). Модель с руками в стороны (Т-поза) — для удобной ручной доработки и рига в Blender. Сгенерировано ИИ (Tencent Hunyuan 3D), условия — как у v3: [RESIDENT_V3.md](../../../docs/godot/RESIDENT_V3.md#происхождение-и-условия).

## Цепочка на сайте

1. Геометрия по одной картинке (владелец): `reference/front_tpose.png`, модель «3D生成 V3.1», 1,5 млн полигонов.
2. Лоу-поли (`低模生成`, «低模拓扑 V1.5»): плотность «низкая», топология из четырёхугольников.
3. UV-развёртка (`UV展开`, «智能展开UV»).
4. Текстура (`纹理绘制`, «图生纹理», одна картинка `reference/front_tpose.png`).
5. Экспорт GLB.

## Что в `resident_bald_lowpoly_textured.glb`

- **Меш:** `mesh_rep_0_ori_repair_quad`, 3742 вершины, **6404 треугольника**; есть NORMAL и TEXCOORD_0.
- **Материал:** PBR, три PNG ~4K — цвет `texture_pbr_20250901`, карта нормалей `…_normal`, metallic-roughness.
- **Размер и ориентация:** около 1 единицы (руки по X от −0,5 до 0,5), у узла поворот 90° по X. Без скелета и анимаций.
- Вес 27 МБ, в основном текстуры 4K: для игры их ужать до 2K.
- SHA-256 начинается с `3188a771fe94c248`.

## Для доработки в Blender

`File → Import → glTF 2.0` и выбрать этот файл. Перед ригом: масштаб до роста ~1,75 м, ступни на Z=0, применить поворот (`Ctrl+A → All Transforms`). Контракт игры (имена материалов, 19 костей, сокеты, клипы) — в [RESIDENT_V3.md](../../../docs/godot/RESIDENT_V3.md) и `art/blender/prepare_resident_v3.py`.
