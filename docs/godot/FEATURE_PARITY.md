| | Работа (Добыча / Стройка) | Удары киркой/топором/руками | Анимации swings/dig/build | Взмахи с инструментом в сокете | In progress (M1/M4) | Синхронно с серверным `harvestHits` |
| | Атака (Melee / Shot) | Струя воды, выпад копьём | Анимации melee и выстрела водомёта | Визуальное событие 1 раз на выпад | Planned (M4) | `ant.melee`, `ant.shot` |
| | Растворение в воде | `ant.dissolved`, уменьшение масштаба | Шейдер размытия / масштабирование | Проверка масштаба и текстуры | Planned (M4) | Дождь и вода смывают глину |

| | Мастерская (Workshop) | Спрайт мастерской | 3D-модель мастерской с наковальней | Производство инструментов | Planned (M4) | Инструменты в наличии |

| | Вода и берега | Анимация воды, маска озера | 3D-шейдер воды с рябью и прозрачностью | Отражения, погружение монстра | Planned (M4) | Северное и южное озёра |
