# Жители за работой — 21.10.2026

Исполнитель — Claude (Opus 5.5), ветка `codex/godot-3d-migration`.

## Что было

Сервер давно присылает работу жителя (`job`, `harvestNodeId`, `harvestHits`, `buildTargetId`, `fishingLurePos`/`fishingTicks`) и вид груза (`carryKind`), но Godot это не показывал: клип `work_gather` никогда не включался, любой груз был одним глиняным комком у груди (сзади его закрывало тело), а второе племя выглядело так же, как первое — цвет применялся только при смене племени, которого после появления не бывает.

## Что сделано

- `EntityRegistry.work_for` по каждому снимку определяет видимую работу по правилам 2D-клиента (`canWork` в `client/src/render/surface/motion.ts`): у узла в пределах 1.6, `state=idle`, `harvestHits>0`, узел не пуст; у стройки `inProgress` в пределах 2.6; рыбалка с наживкой. Дождь, тревога, намокание и груз отменяют работу.
- Инструменты по `resourceNodeTool`: топор у дерева, кирка у скалы, молот на стройке, удочка на рыбалке; хворост, галька и глина — руками.
- Житель проигрывает клип работы лицом к цели (раньше каждый кадр поворот по ходу перебивал разворот), у места работы летят щепки, каменная крошка, комья глины или пыль; дерево вздрагивает от ударов.
- **С 22.10.2026 у модели v3 груз лежит в корзине за спиной, а у каждого занятия своя анимация** (см. [RESIDENT_V3.md](RESIDENT_V3.md)). Ниже — решение для прежней модели, оно действует под `--resident-legacy`.
- Груз по виду: поленья, камень, ком глины, корзина ягод, рыба, мясо. Груз **на голове** (кость `Socket_Head`): с камеры сверху и с юга груз у груди пропадал за круглым телом у всех, кто идёт на север. С грузом включаются обычные клипы ходьбы и покоя — клипы переноски держали руки у груди без предмета. Это осознанная замена решения M1.1 о переноске у груди; интеграционный тест проверяет новое крепление.
- Племена различимы: светлая терракота с охристым поясом и тёмная красно-коричневая глина с голубым поясом.

Файлы: `godot/scripts/world/entity_registry.gd`, `network_resident.gd`, `prop_factory.gd` (`tool`, `carry_load`), `world_view.gd` (дрожь деревьев), `world_observer.gd`.

## Ограничения

- Один общий клип работы для рубки, кирки, копания и стройки; отдельные движения (замах топором сверху, копание) — задача для Blender-анимаций.
- Сбор ягод с куста отдельно не показан: на сервере это поиск еды без работы у узла.
- Рыбалка — поза покоя с удочкой, без лески и поклёвки.
