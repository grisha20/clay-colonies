# Живой мир вместо шаров — 21.10.2026

Исполнитель — Claude (Opus 5.5), ветка `codex/godot-3d-migration`, база `8c5ee1f`.

## Что было не так

После запуска владелец назвал Godot-сборку неиграбельной: «лаги, дёрганье, непонятно, что происходит, нет привлекательного окружения, 2D выглядит лучше». Проверка подтвердила оба направления:

1. **Мира не было.** Все 95 деревьев, 64 куста, камни, хворост, глина, 8 карьеров, рыбы и враги рисовались цветными `SphereMesh`, склад/мастерская/идол/ограда — `BoxMesh`, земля — однотонная оранжевая плоскость, озёра — плоский синий многоугольник. Игрок не мог отличить дерево от куста, а куст от врага, поэтому «что происходит» было непонятно.
2. **Нагрузка и рывки.** На живой QA-партии с 54 жителями `EntityRegistry.update_from_snapshot` занимал **~21 мс главного потока на каждый snapshot** (10 раз в секунду). Причина: навигация каждого жителя для каждой пробы заново перебирала все здания (новые словари footprint на каждое здание) и проверяла многоугольники озёр по всем рёбрам даже на другом конце карты. Отсюда регулярные длинные кадры и лишняя загрузка CPU.

Выбрано одно направление: **читаемый, живой мир для существующей симуляции**. Серверный код, протокол, сохранения и 2D-клиент не изменялись.

## Что сделано

Весь мир генерируется процедурно в Godot (без новых зависимостей и бинарных ассетов): лепные «глиняные» формы с ручной неровностью, палитра — в вертикальных цветах, кэш мешей по варианту.

| Объект snapshot | Было | Стало |
|---|---|---|
| Земля | однотонная плоскость | луг с вариациями цвета, сухие пятна, песчаные вытоптанные лагеря, утоптанная земля у очага, дворы у построек, мокрый песок у берега |
| Тропы | — | **тропы протаптываются там, где реально ходят жители**, и медленно зарастают (только визуально, не сохраняются) |
| Озёра | плоский полигон | вода с мелководьем, глубиной, рябью и пеной по авторскому контуру из `shared/surfaceTerrain.ts`; камыши по берегам |
| Деревья (`tree`) | зелёный шар | 3 силуэта крон, стадии `sapling/young/mature`, крона редеет и желтеет по мере вырубки |
| Кусты еды (`food`) | красный шар | куст с ягодами, число ягод = запасу (как в 2D), обобранный куст остаётся пустым |
| Камни, галька, хворост, глина | шары | валуны, россыпь гальки, связки палок, влажные глиняные комья |
| Карьеры (`deposits`) | невидимы / шары | раскопанная красная/серая площадка, вал из земли, глиняная стенка или скальный выход; содержимое убывает с запасом |
| Склад, мастерская, идол | коробки | открытый склад (кувшины, поленница, камни, глина), мастерская под двускатной крышей, глиняный идол |
| Хижина | модель 3.16 м внутри footprint 8×4.6 | модель растянута на серверный footprint — жители больше не обходят пустоту |
| Ограда и ворота | кубы | колья с жердями между соседними клетками того же племени (топология `fenceLayout.ts`), ворота со створками |
| Стройка | непрозрачно | полупрозрачный «призрак», уплотняется с прогрессом |
| Костёр | модель | живое пламя, мерцающий свет, бревна-скамейки; гаснет при `colony.fire ≤ 0.05` |
| Паук, жук, озёрный монстр, рыбы | чёрные/голубые шары | узнаваемые фигурки, плавно скользят к новой позиции и поворачиваются по ходу |
| Декор | — | ~28 тыс. пучков травы, цветов, камыша и камешков (MultiMesh по чанкам 40×40, вне воды и полян, колышутся на ветру) |
| Освещение | — | тёплое солнце, SSAO для контакта с землёй, мягкий glow огня |

Файлы:
- `godot/scripts/world/prop_factory.gd` — процедурные модели и кэш.
- `godot/scripts/world/ground_decor.gd` — декор на рабочем потоке, загрузка готовых чанков по 6 за кадр, ближние к камере первыми.
- `godot/scripts/world/trail_map.gd` — память троп (240×240, L8).
- `godot/shaders/ground.gdshader`, `water.gdshader`, `grass_tuft.gdshader`, `surface_common.gdshaderinc`.
- `godot/scripts/world/world_view.gd` — сопоставление snapshot → props, обновление только изменившихся объектов, прогрев вариантов моделей по одному за кадр.
- `godot/scripts/world/surface_navigation.gd`, `surface_terrain.gd` — ускорение без изменения результатов (индекс препятствий на массив построек с ключом по содержимому; bbox перед точной проверкой озера).
- `godot/scripts/game/world_observer.gd` — в фоне/свёрнутым окно ограничено 20 FPS.

- Изолированный QA-сервер `scripts/godot/qa_server.py --port 8791 --state-dir tmp/qa/visual_state`, пользовательское сохранение не использовалось.

## Ограничения и следующие шаги

- Художественное одобрение владельца не получено; это первый цельный образ, а не финал.
- Модели процедурные (GDScript), не Blender-ассеты. Их легко перенести в Blender позже, сохранив силуэты.
- Хижина — прежняя GLB, растянутая неравномерно; стоит заново вылепить её под footprint.
- Тропы живут только в текущем сеансе клиента; после переподключения протаптываются заново.
- Жители, переносимые ресурсы, дождь, ночь, следы ног, анимации врагов (ноги паука не шагают) не трогались.
- Остаются редкие длинные кадры на 5× (до ~110 мс один раз за 10 с) и ~5.7 мс CPU на snapshot в `EntityRegistry` — следующий кандидат на профилирование.
- Ограничение 20 FPS в фоне проверено только по коду, не замером.
