# Программа приёмочных испытаний (Acceptance Checklist)

### M0: Аудит и среда
- [x] Версии, оборудование, ветка и матрица паритета проверены
- [x] Защита QA-путей и запрет fixture внутри state-dir, обычный конкурентный захват: текущие 7 тестов проходят
- [ ] Конкурентное stale recovery сохраняет исключительное владение, release не удаляет сменившегося владельца
- [ ] Сбой записи/замены fixture сохраняет прежнее QA-состояние
- [ ] Подтверждены ненулевой выход дочернего сервера, очистка собственного дерева и загрузка настоящего позитивного fixture

### M1: Визуальный образец
- [x] Есть запускаемая лаборатория, исходники, генераторы, GLB и пять секундных клипов
- [x] Прежние ошибки весов торса и открытых краёв устранены
- [x] Переноска подключена к скелетному сокету; положения кистей согласованы с размером груза
- [x] Реальные подошвы нынешнего импортированного меша в окне опоры walk/carry_walk имеют ошибку <1 мм; подтверждено независимым skinning
- [x] Шесть стадий walk/carry_walk × 0,25×/1×/5× проходят текущие пороги по высоте, погружению и дрейфу
- [x] Подъём +0,5 м и рассогласование скорости дают ожидаемый FAIL
- [x] Камеры учитывают направление тела, профили действительно показывают бок
- [x] Материалы пропсов назначены, есть пламя и геометрический вход хижины, подтверждён лучом
- [x] Сняты новый 30-секундный тур и девять кадров; Codex также проверил свежий GPU-кадр carry
- [ ] Отдельно проверены пауза/возобновление, разворот, отсутствующие контакты и проникновение: восьми стадий для этой отметки недостаточно
- [ ] После художественных изменений повторно подтверждены реальные подошвы и контакт кистей
- [ ] Мягкий цельный силуэт без механических стыков, материал головы без резкой границы, пояс-шнур и фактура лепки
- [ ] Согласованный художественный образ лагеря, полный медленный визуальный цикл и игровой масштаб
- [ ] M1 принят целиком после оставшихся исправлений
- [ ] Художественный образ утверждён владельцем проекта

### M2: Сетевой клиент реального времени
- [ ] Подключение WebSocket к серверу (порт по умолчанию 8788 в QA)
- [ ] Приём и парсинг верхнеуровневого JSON-снимка `NetworkWorldSnapshot` (протокол v21)
- [ ] Индексация сущностей по ID (ant, building, foodSource, resourceNode, enemy, fish)
- [ ] Плавная интерполяция движения с буферизацией 100 мс (соответствует `broadcastIntervalMs=100`)
- [ ] Корректная обработка скоростей симуляции (0 / пауза, 1x, 5x, 20x, 50x)
- [ ] Безопасный reconnect без дублирования сущностей

### M3: Управление и паритет строительства
- [ ] Игровая 3D-камера: сдвиг, границы карты (480x480), плавный зум, центрирование на лагере
- [ ] Выбор и подсветка жителей/зданий/ресурсов кликом мыши (3D Raycast)
- [ ] Панели HUD: ресурсы склада, население, задачи партии, тревога, скорость
- [ ] Рисование зон добычи (`paintZone: harvest`) и запрета (`forbid`)
- [ ] Полупрозрачный 3D-предпросмотр зданий перед установкой с проверкой коллизий и цены
- [ ] Непрерывное рисование секций забора и установка ворот с поворотом (R)
- [ ] Валидация wire-команд через существующий `parseCommand` сервера

### M4: Полнота игрового мира
- [ ] Полный комплект моделей: хижина, склад, мастерская, идол, костёр, забор, ворота
- [ ] Все ресурсы: глина, палки/деревья (3 стадии), камни/скалы, плоды, рыба, мясо
- [ ] Карьеры: глиняный карьер (`clay-pit`), каменная каменоломня (`stone-quarry`)
- [ ] Существа: паук (атака, волочение добычи), жук, озёрный монстр (плавание и берег), рыбы
- [ ] Декоративное поведение короля и королевы (прогулка, укрытие у горящего костра или служебной точки хижины при дожде/тревоге/опасности)
- [ ] Погодные эффекты: предупреждение, дождь, растворение глиняных тел, тушение костра
- [ ] Финальные условия матча: победа/поражение, диалоговое окно исхода

- [ ] Измерение производительности: стабильные 60 FPS при 1080p со 100 жителями на RTX 4070
- [ ] Стресс-тест: замер частоты кадров при 300 и 500 жителях
- [ ] Длительный прогон партии (не менее 30 минут) без утечек памяти и рассинхронизации
- [ ] Сборка Windows x64 исполняемого файла (`.exe`)
- [ ] Полный коммит всех исходников и push в origin ветки `codex/godot-3d-migration`
- [ ] Передача отчёта для совместной верификации с Codex и пользователем
