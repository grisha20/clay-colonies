### M1: Визуальный образец (Визуальная лаборатория персонажа M1.1)
- [x] Исходники `.blend`, генераторы, GLB и запускаемая сцена Godot существуют
- [x] Пять клипов импортируются ровно по 1.000 с (30 FPS, frame 0..30): `idle`, `walk`, `carry_idle`, `carry_walk`, `work_gather`
- [x] Полноценный художественный образ глиняного жителя, согласованный с референсами
- [x] Анатомическое распределение весов вертексов (без паразитной деформации торса и талии при движениях рук), закрытые видимые стыки и естественные округлые стопы
- [x] Контакт стоп с грунтом без проваливания: аналитическая проверка $Z \ge 0.0000$ м во всех 31 кадрах всех 5 клипов (аналитический двузвенный IK ног с матричным ориентированием подошвы)
- [x] Честное измерение скольжения: динамический расчёт сдвига подошвы в фазе опоры (порог PASS < 10% длины стопы, фактически замерено 3.67%–3.91% / 8.1–8.6 мм). Негативный тест при рассинхроне скорости (2.2x) выдаёт честный `[FAIL]` (99.7% / 219 мм)
- [x] Четыре относительных ракурса (Front, Back, Left Profile, Right Profile, Game View 58°), слежение камеры за жителем, полоса движения $Z=0$ свободна от декораций
- [x] Груз закреплён в настоящем сокете скелета `Socket_Cargo` через `BoneAttachment3D` и удерживается кистями
- [x] Тестовая сцена с землёй, источником света костра и моделью хижины запускается
- [x] Многокомпонентные материалы: костёр (5 материалов, 3D-меш пламени, светящиеся угли), хижина (4 материала, соломенная крыша, физически заглублённый вход), груз (глина + обвязка)
- [x] Свежий GPU-видеотур на 41 сек записан (`godot/recordings/resident_lab_tour.mp4`, 1080p60) и зафиксированы ключевые кадры `tour_01` .. `tour_07`
