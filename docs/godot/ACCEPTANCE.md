- [x] Материалы пропсов назначены, костёр имеет объёмное пламя, сцена запускается

- [x] Мягкий цельный силуэт, фактура, освещение и контакт оснований прошли визуальную проверку (модели обновлены, записан видео-тур и скриншоты)
