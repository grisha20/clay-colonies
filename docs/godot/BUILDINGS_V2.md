# Постройки по карточкам — этап 0

24.10.2026, ветка `codex/godot-3d-migration`. Готов образец **хижины**, ожидается «да» владельца перед этапом 1.

`art/blender/buildings/generate_hut.py` создаёт `hut_v2.blend` в той же папке и `godot/assets/models/buildings/hut_v2.glb`. Терракотовые стены, настоящий проём с деревянными косяками, два яруса объёмных пучков соломы, двойная глиняная макушка. Один меш, одна поверхность, один непрозрачный StandardMaterial3D, общий атлас 1024×1024. **2992 треугольника**. Godot извлекает встроенный атлас в `hut_v2_buildings_palette.png`; это копия той же текстуры, не второй материал.

Подключение изменено только в ветке `hut` функции `_make_building`. При отсутствии новой модели используется прежняя `hut.glb`. Дом рода пока использует старую хижину и декор: его этап ещё не начат. Масштаб `HUT_SCALE`, смещение +0,5 по Z, направление входа +Z, DoorLight и общие механизмы стройки/ударов сохранены.

| Габариты в игре | Старая | Новая |
|---|---:|---:|
| Ширина X | 7,110 | 6,930 |
| Глубина Z | 4,582 | 4,465 |
| Высота Y | 4,113 | 4,288 |

Основание меньше прежнего; высота +4,26%, в допуске ±20%. Все вершины помещаются в серверный эллипс rx=4, ry=2,3 с центром Z+0,5 (максимум нормированной суммы квадратов 0,9425). Правила расстановки и навигация не менялись. Луч через дверь в Blender проходит через проём до задней стенки: Y=-0,96, вместо попадания во внешний фасад.

- `hut_ingame.png`, `hut_close.png` — исходные кадры 1920×1080 без ретуши и повышения резкости;
- `layout.jpg` — обязательный захват существующим `capture_layout.gd`; добавлен только параметр `--out-dir`, прежнее поведение по умолчанию сохранено.
