## 6. Ловушки окружения

- **Правки с кириллицей.** Много файлов с CRLF, `sed` с многострочными шаблонами часто не срабатывает. Рабочий способ — скрипт `patch.cjs` в scratchpad, но scratchpad новой сессии будет другим, поэтому пересоздать. Смысл скрипта: читает файл, нормализует CRLF, заменяет каждую пару from→to (каждое from встречается ровно один раз), возвращает CRLF.
- **Heredoc в bash ломается на апострофах** внутри одинарных кавычек.
- **`python` в bash — заглушка Microsoft Store.** Использовать `py -I`, `node` или Python внутри Blender.
- **Классификатор auto-mode блокирует** `git checkout --` и перезапись отслеживаемых файлов без явного разрешения владельца. Сначала спросить.
- **Headless-окно Godot масштабирует кадр под 1920×1080.** Для кадров запускать не headless, с `--resolution 1920x1080`.
- **Остановка QA-серверов** после работы:
  ```powershell
  Get-NetTCPConnection -LocalPort N -State Listen | % { Stop-Process -Id $_.OwningProcess -Force }
  ```
- **Hunyuan 3D** (через Chrome владельца, расширение Claude in Chrome):
  - цепочка: 低模生成 «低», 四边面 → UV展开 智能展开UV → 纹理绘制 图生纹理 (загрузить картинку через `file_upload`) → 下载 → glb;
  - текстура генерируется медленно, до 10+ минут: не ждать, попросить владельца написать «готово»;
  - скачанное лежит в `C:\Users\Степан\Downloads`.
