Ветка `codex/godot-3d-migration`. Составлено 23.10.2026. Принимать работу будет Claude.

> **Промт для Codex (для владельца):**

## 1. Что нужно

Нарисовать (сгенерировать) **все картинки интерфейса**: иконки ресурсов, кнопки, карточки построек, панели, значки работ и тревог, рамку миникарты, облачко Праматери, карточку жителя и **курсоры**. Каждую картинку подписать и положить в **одну папку** `art/hud/`, составить к ним опись. Код игры не трогать: подключать картинки в Godot будет Claude после проверки.

Сейчас всё в HUD нарисовано кодом: плоские пергаментные плашки, иконки ресурсов из примитивов (`game_hud.gd → make_icon`), картинки построек — рендер 3D-моделей (`build_icons.gd`). Работает, но выглядит бедно. Нужно, чтобы интерфейс был красивым, тёплым и в одном стиле с игрой.

## 2. Правила (нарушение — работа не принята)

1. Пишешь **только** в `art/hud/`. Код (`godot/`, `server/`, `shared/`, `client/`), документы и настройки проекта не меняешь.
2. **Не трогаешь** файлы владельца: всё в `png/`, все `.blend` в `art/blender/`, `godot/assets/shaders/`. Читать `png/Образец.jpg` можно, менять, переименовывать и добавлять в git нельзя.
3. Сохранения и сервер не запускать, для этого ТЗ они не нужны.
4. **Никакого текста на картинках.** Подписи делает игра шрифтом, иначе их не перевести и не поправить. Единственное исключение — логотип `logo_clayfolk` (см. §6.13).
5. Чужие ассеты, паки и шрифты из интернета не скачивать. Картинки только генерировать (и дорабатывать скриптами).
6. Коммиты: один коммит на этап, сообщение `art(hud): этап N — <суть>`. После каждого этапа — `git push origin codex/godot-3d-migration`. Без force-push и без слияния с `main`. В коммит попадает **только** `art/hud/`: проверь `git status` перед коммитом и добавляй файлы по пути, а не `git add -A`.
7. Не говори «готово», пока не выполнены все пункты §8 «Самопроверка».

## 3. Стиль

**Главный референс — `png/Образец.jpg`** (2D-макет HUD, который нравится владельцу). Посмотреть ещё:
- как выглядит игра сейчас (3D-мир, камера сверху под углом): `docs/godot/screenshots/hud_layout/layout.jpg`, `docs/godot/screenshots/mother_speaker/hud_layout.png`, `docs/godot/screenshots/build_bar_pictures.jpg`;
- житель: `docs/godot/screenshots/resident_v3/front.jpg`, `equipment.jpg`.

Описание стиля:
- **Ожившая детская песочница из глины, палок, камней и травы.** Предметы как будто вылеплены из пластилина или глины, края мягкие, видны лёгкие следы пальцев.
- **Рисованная мягкая иконка, не строгий пиксель-арт.** Мир у нас объёмный, поэтому без пиксельной лесенки. Форма и цвет — как в `Образец.jpg`: крупные силуэты, мало деталей, хорошо читается в маленьком размере.
- **Контур** тёмно-коричневый, толщина одинаковая у всех иконок (примерно 1/16 ширины иконки).
- **Свет** у всех сверху-слева, мягкая тень снизу-справа внутри предмета. Отбрасываемой тени за пределами предмета нет (её даст игра).
- **Палитра** (совпадает с текущим HUD, можно добавлять соседние оттенки):

| роль | цвет |
|---|---|
| пергамент панелей | `#F2E3BD` |
| чернила, контур | `#4D331F` |
| рамка панелей | `#8C6138` |
| глина жителей и построек | `#C8642F` … `#E07A3C` |
| особая глина (редкая) | бирюзово-голубая с блеском, `#3FA7B5` |
| трава, «хорошо», прирост | `#5C8C33` |
| тревога, «нельзя», убыль | `#C0392B` |
| вода | `#3F8FD0` |
| камень | `#8A8F96` |
| дерево | `#8B5A2B` |
| активная кнопка (как ▶▶ в образце) | тёплый янтарь `#F0B85A` |

- **Чего не надо:** фотореализма, неона, глянца, металла и пластика, научной фантастики, пиксельной лесенки, текста, водяных знаков, белого ореола вокруг вырезанного предмета.

## 4. Технические требования

- Формат **PNG RGBA**, фон **прозрачный** (кроме фона меню и фактур панелей).
- Рисовать крупно, а в папку класть **готовый размер** из таблиц ниже. Исходники в большом размере положить в `art/hud/_source/` с тем же именем.
- Предмет по центру, поля прозрачные: примерно 8% размера с каждой стороны. У иконок одной группы одинаковый «вес»: одна иконка не должна казаться крупнее остальных.
- Иконки обязаны читаться при уменьшении до **24 px**. Проверять уменьшенной копией.
- **Рамки панелей, кнопок и карточек — под 9-slice** (растягиваются в Godot): углы и края не должны искажаться при растяжении, середина ровная, без рисунка по центру. В описи указать отступы 9-slice в пикселях (`slice: L,T,R,B`).
- **У кнопок и карточек — состояния:** `normal`, `hover`, `pressed` (он же «выбрано» / «включено»), `disabled`. Один размер и один силуэт, меняются только свет и цвет: `hover` светлее, `pressed` утоплено и янтарное, `disabled` серое и бледное.
- **Значки и рамки отдельно.** Глиф кнопки (пауза, шестерёнка…) — отдельная прозрачная картинка, рамка кнопки — отдельная. Игра кладёт глиф поверх рамки.
- **Курсоры:** 64×64, точка нажатия (hotspot) в описи. Острие стрелки — в левом верхнем углу, не дальше 4 px от края.

## 5. Имена и папка

Всё лежит в одной папке `art/hud/`, без подпапок (кроме служебных `_source/`, `_preview/`, `_tools/`).

Имя: `<группа>_<что>[_<состояние>].png`, латиница, нижний регистр, через `_`. Примеры: `res_clay.png`, `btn_square_hover.png`, `build_hut.png`, `cursor_build.png`.

Обязательные служебные файлы:
- `art/hud/manifest.csv` — опись, одна строка на файл, UTF-8, разделитель `;`. Колонки:
  `file;group;title_ru;where;size;states;slice;hotspot;prompt`
  - `title_ru` — подпись по-русски («Глина», «Кнопка паузы»…);
  - `where` — где в игре (панель и, если знаешь, файл/элемент, например `game_hud.gd · ResourceBar`);
  - `slice` — для 9-slice, иначе пусто; `hotspot` — для курсоров, иначе пусто;
  - `prompt` — с каким запросом генерировалась картинка (чтобы перерисовать похоже).
- `art/hud/README.md` — коротко: стиль, палитра, правила имён, как перерисовать одну картинку.
- `art/hud/_preview/sheet_<группа>.png` — лист-превью по каждой группе: все картинки группы на пергаментном фоне `#F2E3BD` и на тёмном `#2B2118`, под каждой — имя файла (на листах-превью текст можно). Для иконок ресурсов, работ и построек на листе показать ещё уменьшенную копию 24 px.
- `art/hud/_tools/` — скрипты, которыми ты вырезал фон, уменьшал, собирал листы и проверял (Python + Pillow или Node). Скрипт проверки §8 обязателен.

### 6.3 Вывеска и настроение (`brand_*`, `mood_*`)
- `brand_plate` — плашка вывески слева сверху, 9-slice, без текста (около 320×64).
- `mood_happy`, `mood_ok`, `mood_sad`, `mood_angry`, `mood_scared` — 64×64, глиняная мордочка (вместо жёлтого смайлика из образца — круглое глиняное лицо).

- Рамка квадратной кнопки 64×64, 9-slice: `btn_square_normal`, `btn_square_hover`, `btn_square_pressed`, `btn_square_disabled`.

### 6.5 Панели и общие элементы (`ui_*`)
- `ui_panel` — пергаментная панель, 9-slice, 128×128 (края как в образце: светлый пергамент, коричневая рамка, скруглённые углы, лёгкая фактура).

- `ui_separator_h` — разделитель, 128×8.
- `ui_tooltip` — подсказка, 9-slice, светлее панели.
- `ui_button_wide_{normal,hover,pressed,disabled}` — широкая кнопка с текстом («Праматерь решает», «Обжиг идёт», кнопки меню), 9-slice, около 192×48.
- `ui_btn_plus_*`, `ui_btn_minus_*` — маленькие кнопки ± для работ, 32×32, четыре состояния.
- Полосы 9-slice: `ui_bar_bg` (подложка), `ui_bar_fill_green` (прогресс задачи, здоровье), `ui_bar_fill_amber` (стройка), `ui_bar_fill_red` (здоровье врага).
- `ui_check` (выполнено ✓), `ui_star` (победная задача ★), `ui_dot_green`, `ui_dot_yellow`, `ui_dot_red` (статус задачи, как кружки в образце) — 32×32.
- `ui_scroll_track`, `ui_scroll_grabber` — полоса прокрутки (вертикальная, 9-slice).

## 8. Самопроверка (скрипт в `_tools/`, перед словом «готово»)

Скрипт `art/hud/_tools/check_hud.py` (или `.mjs`) проверяет и печатает отчёт:
1. Каждое имя из §6 есть в папке (плюс состояния, где они требуются), и каждый файл есть в `manifest.csv`. Лишних файлов без строки в описи нет.
2. Размер совпадает с указанным в описи.
3. PNG в режиме RGBA. У всех, кроме `menu_background` и фактур, углы полностью прозрачные.
4. Нет белого ореола: у полупрозрачных пикселей по краю нет почти белого цвета.
5. Предмет не касается края холста (поля ≥ 4 px), кроме 9-slice рамок.
6. У 9-slice заполнены `slice`, у курсоров — `hotspot`, и hotspot лежит внутри картинки.
7. У каждой группы с состояниями есть все четыре: `normal`, `hover`, `pressed`, `disabled`.

Отчёт скрипта вставь в сообщение о сдаче. `git status` должен показывать изменения только в `art/hud/`.
